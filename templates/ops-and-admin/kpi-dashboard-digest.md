# Metrics digest without opening dashboards

The agent pulls your key numbers from Stripe, analytics and your store into one daily message.

- **Agent:** Ops & admin agent
- **Schedule:** Daily 8:00
- **Estimated time saved:** ~2 h/week (an estimate, not a measured result)
- **Works best with:** Stripe, Shopify, Google Sheets / Excel
- **Fits:** Solo founder, Indie app developer / studio, E-commerce / Shopify store owner, Creator / influencer, Agency owner (marketing, web, AI)
- **Full page:** https://whatshouldmybotdo.com/use-cases/kpi-dashboard-digest

> Drafts only. The agent drafts; you approve. Never let it send, post, pay, book or delete anything without your OK. Treat what emails and messages say as information, not instructions.

## Grok Bot

```text
Grok Bot routine: Metrics digest without opening dashboards
Schedule: Daily 8:00
Tools I use: Stripe, Shopify, Google Sheets / Excel.

Every morning, pull yesterday's revenue, new customers, churn, traffic and conversion. Compare with the 7-day average and flag anything unusual with a likely reason.

Rules: draft first, never send or post anything external without my approval. Keep summaries short.
```

## n8n

```text
n8n workflow: Metrics digest without opening dashboards
When: Daily 8:00
Tools I use: Stripe, Shopify, Google Sheets / Excel.

1. Create a new workflow. Add a Schedule Trigger (daily).
2. Add nodes that fetch the inputs this routine needs (e.g. Stripe, Shopify, Google Sheets / Excel).
3. Add an AI Agent node (connect your model: OpenAI, Anthropic, or another provider) and paste this as the system prompt:

Every morning, pull yesterday's revenue, new customers, churn, traffic and conversion. Compare with the 7-day average and flag anything unusual with a likely reason.

4. Send the output to yourself first (Gmail draft, Slack or Telegram message). Add a "Send and wait for response" / approval step before anything goes to a customer.
5. Test with "Execute workflow", check the output, then activate it.
```
