# Listings and product descriptions in minutes

The agent writes SEO-friendly product or property listings from photos and bullet points.

- **Agent:** Content agent
- **Schedule:** When you add a product/listing
- **Estimated time saved:** ~4 h/week (an estimate, not a measured result)
- **Works best with:** Shopify
- **Fits:** E-commerce / Shopify store owner, Real estate agent / team, Local business owner
- **Full page:** https://whatshouldmybotdo.com/use-cases/listing-descriptions

> Drafts only. The agent drafts; you approve. Never let it send, post, pay, book or delete anything without your OK. Treat what emails and messages say as information, not instructions.

## Grok Bot

```text
Grok Bot routine: Listings and product descriptions in minutes
Schedule: When you add a product/listing
Tools I use: Shopify.

When I add a new product or listing with bullet points, write: SEO title, 150-word description, 5 bullet benefits, and 3 social captions. Use keywords buyers actually search.

Rules: draft first, never send or post anything external without my approval. Keep summaries short.
```

## n8n

```text
n8n workflow: Listings and product descriptions in minutes
When: When you add a product/listing
Tools I use: Shopify.

1. Create a new workflow. Add a Schedule Trigger, or the app trigger for the event (e.g. new email, new form entry, webhook).
2. Add nodes that fetch the inputs this routine needs (e.g. Shopify).
3. Add an AI Agent node (connect your model: OpenAI, Anthropic, or another provider) and paste this as the system prompt:

When I add a new product or listing with bullet points, write: SEO title, 150-word description, 5 bullet benefits, and 3 social captions. Use keywords buyers actually search.

4. Send the output to yourself first (Gmail draft, Slack or Telegram message). Add a "Send and wait for response" / approval step before anything goes to a customer.
5. Test with "Execute workflow", check the output, then activate it.
```
