# Repurpose one piece into ten

One video, podcast or long post becomes threads, LinkedIn posts, shorts scripts and a newsletter section.

- **Agent:** Content agent
- **Schedule:** When you publish
- **Estimated time saved:** ~6 h/week (an estimate, not a measured result)
- **Works best with:** Instagram / TikTok / YouTube, X / Twitter, LinkedIn, Postiz / Buffer
- **Fits:** Creator / influencer, Consultant / coach / freelancer, Agency owner (marketing, web, AI), Solo founder, E-commerce / Shopify store owner
- **Full page:** https://whatshouldmybotdo.com/use-cases/repurpose-one-into-ten

> Drafts only. The agent drafts; you approve. Never let it send, post, pay, book or delete anything without your OK. Treat what emails and messages say as information, not instructions.

## Grok Bot

```text
Grok Bot routine: Repurpose one piece into ten
Schedule: When you publish
Tools I use: Instagram / TikTok / YouTube, X / Twitter, LinkedIn, Postiz / Buffer.

When I publish a long piece, repurpose it into: 1 X thread, 3 standalone X posts, 2 LinkedIn posts, 3 short-video scripts and 1 newsletter section. Queue drafts in my scheduler for approval.

Rules: draft first, never send or post anything external without my approval. Keep summaries short.
```

## n8n

```text
n8n workflow: Repurpose one piece into ten
When: When you publish
Tools I use: Instagram / TikTok / YouTube, X / Twitter, LinkedIn, Postiz / Buffer.

1. Create a new workflow. Add a Schedule Trigger, or the app trigger for the event (e.g. new email, new form entry, webhook).
2. Add nodes that fetch the inputs this routine needs (e.g. Instagram / TikTok / YouTube, X / Twitter, LinkedIn).
3. Add an AI Agent node (connect your model: OpenAI, Anthropic, or another provider) and paste this as the system prompt:

When I publish a long piece, repurpose it into: 1 X thread, 3 standalone X posts, 2 LinkedIn posts, 3 short-video scripts and 1 newsletter section. Queue drafts in my scheduler for approval.

4. Send the output to yourself first (Gmail draft, Slack or Telegram message). Add a "Send and wait for response" / approval step before anything goes to a customer.
5. Test with "Execute workflow", check the output, then activate it.
```
